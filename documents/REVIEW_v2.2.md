# 연구계획 v2.1 전면 검토 — 증거 기반 판정 (초안)

**작성:** 2026-09-13 · **근거:** F-001~F-040, ADR-001~018 · **상태:** 초안. 결정 반영: §2.2 검증 불가(보류), §6.1 ProsQA 유지·이정표 명시 (2026-09-13). 뿌리 ② 의 처방은 Ablation E 결과 뒤 결정.

> 원칙: 주장마다 **증거(F-번호) → 판정(유지 / 수정 / 기각 / 유보)** 를 적는다. 판정 없이 바꾸지 않고, 증거 없이 판정하지 않는다. 이 문서 위에서 v2.2 제안서를 개정하고, 개정 항목마다 ADR 을 남긴다.

## 0. 한 문장 요약

**동결 백본 + 답만 감독하는 학습으로는, 어떤 방출 구조·어떤 수렴 장치·어떤 커리큘럼을 붙여도 엔진이 수신기가 질문만 읽고 도달하는 값(No-CoT, 0.660) 위에 아무것도 얹지 못한다 (F-038·F-039).** 이것이 지금까지 모든 절제가 ±1%p 안에서 같은 값을 낸 이유이며, 검토의 출발점이다.

## 2. 무엇이 남고 무엇이 간다

**남는다 (증거가 지지하거나 중립):**
- 동결 base 가중치 + 디코딩 전용 LoRA (I1·I9). 검증됐고 비용도 싸다.
- 2원화 학습 — **귀속 도구로서**. Phase A/B 체크포인트 비교가 F-038 을 드러냈다. 다만 커리큘럼과의 순서는 바꾼다.
- 게이트·ADR·FINDINGS 규율. 버그 다섯(F-028·029·031·035 + anytime 분모)과 영(零) 결과 셋(F-034·038·039)을 걸러냈다.
- 고친 엔진 배관: 잔차 스택(F-029), 상태·혼합 정규화(ADR-017), 경로 통합(F-031). 무엇을 만들든 이 위에서 만든다.
- YAML 주도 스윕·slurm 배선·에폭별 체크포인트.

**간다 (증거가 기각):**
- "답 NLL + 콜드 스타트" 를 기본 학습으로 두는 것 (§5.2).
- "Phase A 에서 커리큘럼" 이라는 순서 (§5.1).

**보류 (검증 불가):**
- "압축 병목" (§2.2) — 기각이 아니라 검증 조건 미충족. 외부 연구는 벡터 개수의 중요성을 지지한다. 엔진이 정보를 싣는 조건에서 다시 잰다.

**바뀐다 (증거가 수정을 요구):**
- §4.1 사고 메모리의 구성 — 샘플 불변성을 깨는 것이 선결.
- §6.1 과제 — 엔진의 기여가 보일 여지가 있는 곳으로.

## 3. 뿌리 문제 둘 — 검토의 축

모든 영 결과가 두 뿌리로 모인다. 순서대로 풀어야 하고, 하나만 풀면 나머지가 가린다.

### 뿌리 ① 메모리가 질문을 담지 않는다 (§4.1, F-030)

`H_last` = 마지막 질문 토큰의 12층 은닉 상태. ProsQA 질문은 모두 "… Is X a Y or Z?" 로 끝나므로 마지막 토큰의 상태가 **97% 같은 방향**이고, 어댑터를 거치면 **99.5%** 다. 정제 엔진은 이 거의 같은 입력을 받아 거의 같은 궤도를 돈다. Δ 가 샘플에 반응하지 않고(F-030), 홉과 무관하고(F-037), 궤적에 답에 없는 정보가 실리지 않는다(F-038).

이건 학습으로 안 풀린다. 어댑터가 공유 성분을 지우도록 학습될 압력이 없고(손실은 답만 본다), 특징축 정규화는 배치 간 공유 성분을 못 지운다.

**재설계 후보 (결정 아님):**
| 후보 | 내용 | 판정 실험 |
|---|---|---|
| ①-a 공유 성분 제거 | 어댑터 앞에서 학습셋 평균(또는 상위 k 주성분)을 빼고 화이트닝 | R⁰ 코사인 0.995 → ? 측정. 재학습 없이 통계만으로 사전 확인 가능 |
| ①-b 질문 전체 풀링 | 마지막 토큰 대신 질문 전 토큰을 층별 어텐션 풀링(§4.1 의 H_pool 은 이미 있음 — 비중을 키우거나 H_last 를 버림) | `memory.composer` 축 절제. 기존 코드 |
| ①-c 위치 선택 | 마지막 토큰이 아니라 질문 본문(전제 부분)의 상태 | 위치 규칙 절제 |
| ①-d 다중 위치 메모리 | 메모리를 [L × d] 가 아니라 [T' × L × d] (핵심 토큰 T' 개) | 아키텍처 변경 — 엔진 입력 축이 바뀜 |

**①-a 사전 측정 완료 (F-040):** 학습셋 평균 하나를 빼면 val 샘플 간 코사인 **0.9755 → 0.0005**, 유효 랭크 37 → 150. 화이트닝·주성분 제거는 추가 이득이 작다. **공유 성분은 고정 벡터 하나다.** ①-a 를 R2 의 후보로 확정한다 — 어댑터 앞 고정 중심화, 학습셋에서 한 번 추정, 버퍼 저장.

### 뿌리 ② 학습 신호가 답 하나다 (§5, F-038·F-039)

답은 한 문장이고 결정 토큰은 최종 개체어 하나다. 그 신호로 엔진이 배울 수 있는 최선은 "LoRA 가 질문에서 직접 읽는 것" 을 흉내 내는 것이고, 그건 LoRA 가 더 잘 한다. 중간 추론에 대한 감독이 없으면 궤적에 답에 없는 정보가 실릴 이유가 없다.

커리큘럼(§5.1)이 그 감독을 주려 했으나, **동결 백본은 언어 추론을 못 해서 흡수할 원본이 없다** (F-039). Coconut 의 순서(CoT 미세조정 → 잠재화)를 따르려면 커리큘럼 동안 수신기(LoRA)가 살아 있어야 하고, 그러면 "Phase A 동결" 이 깨진다.

**재설계 후보:**
| 후보 | 내용 | 대가 |
|---|---|---|
| ②-a 순서 교체 | Phase 0: LoRA 로 CoT-SFT (언어 추론 확보) → Phase A': LoRA 동결·엔진 학습 + 커리큘럼 → Phase B: LoRA 재정렬 | 2원화 귀속이 "동결 base vs LoRA" 가 아니라 "CoT-LoRA 고정 vs 재정렬" 로 바뀜. 여전히 분해 가능 |
| ②-b 깊은 감독 | 사이클 m 의 판독을 CoT 단계 m 에 맞춘다 (`objective.deep_supervision`, 이미 구현) | 스텝-토큰 1:1 대응을 가정 — §5.1 은 이를 명시적으로 부정했다. 재검토 필요 |
| ②-c 증류 | CoT-SFT 된 교사의 은닉 상태를 잠재 토큰이 맞추게 (CODI 방식) | 교사 모델 필요. CODI 가 GPT-2 GSM8k 43.7 로 가장 강함 |
| ②-d 공동 학습 | Phase C 를 기본으로 (엔진+LoRA 동시) | 귀속을 잃음. **Ablation E 진행 중** (`ablation/E_joint`, 2026-09-13 12:37): dynamic_m vs 같은 예산의 No-CoT, 3시드. 예측: No-CoT 를 넘지 못한다 — 엔진 입력의 공유 성분(F-040)과 답 하나짜리 손실은 공동 학습이 건드리지 않는다. 틀리면 §5.0 판정을 바꾼다 |

②-a 가 제안서 정신을 가장 덜 바꾸면서 F-039 를 직접 푼다.

## 4. 과제 (§6.1) — ProsQA 유지 (2026-09-13 결정)

**가장 쉬운 과제에서 Coconut 과 비교해 유의미한 수준이 나오기 전에는 옮기지 않는다.** 과제를 바꾸면 과제 난이도와 아키텍처 문제가 교락되어, 어느 쪽이 결과를 바꿨는지 알 수 없게 된다.

ProsQA 의 기준선 (GPT-2, Coconut Table 1):

| | 정확도 | 뜻 |
|---|---|---|
| 우연 | 50.0 | 이진 |
| **No-CoT (전체 미세조정)** | **76.7** | 첫 이정표 — 이걸 넘어야 "엔진이 무언가를 싣는다" |
| CoT | 77.5 | 언어 추론은 거의 도움이 안 되는 과제 |
| Coconut w/o curriculum | 76.1 | 콜드 스타트는 안 된다 (우리 F-038·F-039 와 같은 현상) |
| **Coconut** | **97.0** | 목표 대역 |
| iCoT | 98.2 | |
| 우리 (동결 수신기 천장) | 66.0 | F-038 |

**이정표:** ① ProsQA 에서 No-CoT 76.7 을 **5시드 유의**로 넘는다. ② Coconut 97.0 과의 격차를 보고한다. ③ 그 뒤 GSM8k-Aug(언어 CoT 가 No-CoT 의 2.6배라 우리 서사에 맞고, 답이 숫자라 감독 신호가 풍부) 로 확장한다. 곱셈은 빠른 진단 무대로만 쓴다.

ProsQA 의 여지 21%p(77 → 98)가 전부 No-CoT **위**에 있다는 점을 잊지 않는다 — 우리는 66 이라 그 여지에 진입조차 못 했고, 진입하려면 동결 수신기의 천장(F-038) 자체를 올려야 한다. 그것이 뿌리 ② 의 처방이 먼저인 이유다.

## 6. 이번 검토가 바꾸지 않는 것

- **결과의 유효성.** F-034 의 킬 판정, F-038 의 영 결과, F-039 의 환각 관측은 모두 사전 등록된 기준과 대조군으로 얻은 것이다. 검토는 그것을 뒤집지 않고 그 위에 선다.
- **규율.** ADR 먼저, 게이트는 실험 전에, 판정과 실행의 분리. 이 규율이 없었다면 F-031(학습·평가 불일치)을 아직 모르고 있었을 것이다.
