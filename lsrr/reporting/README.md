# `lsrr/reporting/` — 보고

## 역할
런 산출물과 외부 공표치를 논문에 실을 수 있는 **표와 그림**으로 만든다.

## 경계
- **한다:** 표 조립, 출처 표기, 그림 생성.
- **하지 않는다:** 지표를 계산하지 않는다(→ `metrics`). 분석하지 않는다(→ `analysis`). **수치를 만들어내지 않는다** — 없는 셀은 비워 둔다.

## 모듈

| 모듈 | 역할 | 상태 |
|---|---|---|
| `provenance.py` | †공표 / ‡자체 측정 표기 규칙, 공란 원칙 | 계획 |
| `tables.py` | 런 인덱스 + `configs/published_numbers.yaml` → 논문 표 | 계획 |
| `figures.py` | anytime 곡선, 파레토, Δ 궤적, α 히트맵 | 계획 |

## 핵심 계약

### 비교 방침 (§6.2) — `provenance.py`가 코드로 강제한다
- 외부 베이스라인(No-CoT, CoT-SFT, iCoT, Coconut, CODI, SIM-CoT)은 **동일 세팅**(학습 데이터·백본 변형·평가 규칙)의 공표치만 인용한다.
- 출처는 **이원 표기**: `†` 공표치 / `‡` 자체 측정.
- **보고가 없는 셀은 원칙 선언 하에 공란으로 둔다.** 다른 세팅의 수치를 끌어와 채우지 않는다. 이 규칙을 코드로 강제하는 이유는, 표를 만들다 보면 빈 칸을 채우고 싶은 압력이 반드시 생기기 때문이다.
- 내부 베이스라인(H+1회 통과 MLP, h⁽ᴸ⁾+동일 SSM, 동FLOPs 어텐션 엔진)은 전부 자체 실행하며 `‡`로 표기한다.
- 모든 표에 정확도와 함께 **추가 FLOPs·평균 사이클·지연**을 병기한다 (I7).

### 핵심 그림
**동일 지연 예산에서의 정확도 곡선**(test-time compute scaling)이 논문의 핵심 그림이다 (§6.2). `figures.py`가 `metrics/pareto.py`의 출력으로 이를 그린다.

### 층화 표기
안정화 사다리 활성 단, 실제 배치 크기, I2 예외 플래그가 서로 다른 런은 같은 셀에서 비교하지 않는다. `tables.py`가 `meta.json`을 읽어 이질적 런이 한 셀에 섞이면 경고한다.
