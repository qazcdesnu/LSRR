# `lsrr/gates/` — 단계별 게이트 판정

## 역할
제안서 §6.3의 단계별 게이트를 **실행 가능한 판정**으로 만든다. 특히 Phase 0 게이트 ③은 **킬 스위치**다.

## 경계
- **한다:** 런 기록을 읽어 게이트 술어를 평가하고 PASS/FAIL과 킬 스위치 신호를 낸다.
- **하지 않는다:** 실험을 돌리지 않는다. 기준을 사후에 조정하지 않는다.

## 왜 코드로 만드는가 (ADR-008)
게이트 ③이 실패하면 **반복의 기여가 없다는 뜻이므로 아키텍처를 재검토한다.** 이 판정이 사람의 눈대중에 맡겨지면 작동하지 않는다 — 실패한 실험 앞에서 기준을 조금 낮추고 싶어지는 것은 자연스러운 일이고, 그래서 기준은 **실험 전에 코드로 고정되어야** 한다.

판정 기준(유의성 검정 방식, 시드 수, 임계값)은 실험 **전에** 설정 파일로 고정하고 런 스냅샷에 포함한다.

## 모듈

| 모듈 | 역할 | 상태 |
|---|---|---|
| `criteria.py` | 게이트 술어 구현 (유의성 검정 포함) | 검증 |
| `definitions.py` | Phase별 게이트 집합 정의와 임계값 | 검증 |
| `report.py` | PASS/FAIL 판정문 + 킬 스위치 신호 | 검증 |

## Phase 0 게이트 (GPT-2 + 곱셈 · ProsQA)

| 게이트 | 술어 | 판정 데이터 출처 |
|---|---|---|
| **①** 자명해 붕괴 없음 | 상태 랭크·층간 분산·쌍별 유사도가 임계 내 | `analysis/collapse.py` |
| **②** M 증가 시 정확도 증가 | 사이클별 정확도 곡선의 단조 증가성 | `metrics/anytime.py` |
| **③** H+MLP 1회 통과 대비 **유의한** 우위 | `engine=hydra_qs` vs `engine=mlp_onepass`, 다중 시드 유의성 검정 | `metrics/aggregate.py` |
| **④** Δ⁽ᵐ⁾ 궤적의 거시적 감소 | 거동 분류에서 `converged` 비율이 임계 이상 | `termination/behavior.py` |

### ③ 실패 시 재검토 순서
게이트 ③은 "반복 정제가 1회 통과보다 낫다"는 본 연구의 최소 주장이다. 실패 시 아래 순서로 원인을 좁힌다 (`ROADMAP.md`와 동일):
1. **깊은 감독 과잉** — 모든 사이클이 이미 답을 알면 반복이 형해화한다. `λ_ds`·`γ` 하향 (§5의 명시 처방).
2. **감쇠 α** — 너무 크면 진동, 너무 작으면 갱신 없음.
3. **안정화 사다리** — 수렴 거동이 `oscillating`/`drifting`이면 `stability` 1단.
4. **메모리 구성** — ADR-004의 문맥 보완항이 실제로 기여하는지 (`composer.type=last_only` 대조).
5. **엔진 구조** — 여기까지 와서야 Ablation C의 문제다.

이 순서는 **싼 것부터, 그리고 제안서가 이미 예상한 실패 양식부터**다.

## 핵심 계약

```
BasePhaseGate.evaluate(run_records) -> GateVerdict { passed, value, threshold, evidence, kill_switch }
```

`kill_switch=True`인 게이트가 FAIL이면 `scripts/check_gates.py`가 비영(non-zero) 종료 코드를 반환한다.

## 의존
`core`, `metrics`, `analysis`, `termination`. (L7.)

## 레거시 참조
없음. 신규 (ADR-008).

## 상태
**검증** — 전 모듈 완료 (M5). `scripts/check_gates.py` 가 ①~④ 에 대해 PASS/FAIL/판정불가를 내고 종료 코드로 신호한다 (0 PASS / 1 FAIL / 2 킬 스위치 / 3 데이터 부족).

**판정 불가는 통과가 아니다.** 데이터가 없으면 FAIL 이 아니라 '미완' 으로 구분해 보고하며, 킬 스위치는 **측정된** 실패에서만 발동한다 — 아키텍처를 재검토하라는 신호는 실측이 뒷받침해야 한다.
